# Domination プラグイン 導入・使い方ガイド

Bukkit/Spigot 系 Minecraft サーバー向けの陣取り合戦（拠点占領）ミニゲームプラグインです。

> **注記**: このREADMEは `Main.java`（プラグイン本体クラス）のみを解析して作成しています。実際のコマンド名・権限名・設定項目の一部は、`CommandManager` や `config.yml` / `gui.yml` の実ファイルが確認できないため、コード上から読み取れる範囲での記載です。実際の挙動と差異がある場合はお手数ですが実機で確認してください。

## 前提条件

- **サーバーソフト**: Bukkit / Spigot 系（Paper等含む）
- **依存プラグイン**: コード上、他プラグインへの依存（`depend` / `softdepend`）は確認できませんでした。単体で動作する想定です。
- **リソースパックの要否**: コード内でカスタムリソースパックを要求する処理（`ResourcePack` 関連API呼び出し等）は見当たりませんでした。**通常のバニラ環境で動作する想定**で、専用リソースパックは不要と思われます。
- **必要なJava/サーバーバージョン**: コードからは不明。`GameMode.ADVENTURE` や `Material.ENCHANTED_BOOK` など標準APIのみ使用しているため、比較的幅広いバージョンで動作すると推測されます。

## 導入方法

1. プラグインのjarファイルをサーバーの `plugins` フォルダに配置し、サーバーを起動（または `/reload`）します。
2. 初回起動時に、以下の設定ファイルが自動生成されます。
   - `plugins/Domination/config.yml`（プラグイン本体の設定）
   - `plugins/Domination/gui.yml`（兵科選択メニューなどGUI関連の設定）
3. `config.yml` に、以下のようなスポーン地点の設定を追加してください（キー構成はコードから読み取れる範囲です）。

```yaml
spawn-location:
  world: world
  x: 0.0
  y: 64.0
  z: 0.0
  yaw: 0.0
  pitch: 0.0

spawn-points:
  red:
    world: world
    x: 100.0
    y: 64.0
    z: 0.0
    yaw: 0.0
    pitch: 0.0
  blue:
    world: world
    x: -100.0
    y: 64.0
    z: 0.0
    yaw: 0.0
    pitch: 0.0
```

   - `spawn-location`: 通常参加時の初期スポーン地点、およびワールドのデフォルトスポーンとして使用されます。
   - `spawn-points.<チーム名>`: 各チームの復帰・リスポーン地点です。`red` はコード内で「該当チームが不明な場合のフォールバック」として使われています。チーム名は自由に追加できると考えられます。

4. 設定変更後は `/Domination` 系のリロードコマンド、またはサーバー再起動で反映してください（`reloadConfig()` は `config.yml` と `gui.yml` の両方を再読込します）。

## コマンド

- `/Domination` — プラグインの管理コマンドの起点です（サブコマンドの詳細は `CommandManager` の実装に依存するため、本READMEでは確認できませんでした。サーバー内で `/Domination help` 等を試すか、実装側に確認してください）。

## プレイヤーの操作・ゲームの流れ

- **参加時**
  - ゲームが進行していない状態で参加すると、インベントリが空の状態でスポーン地点にテレポートされ、アドベンチャーモードになります。
  - ゲーム進行中に一度切断して再接続した場合、**切断前のインベントリ・防具がそのまま復元**され、所属していたチームのスポーン地点に戻されます。
- **兵科（クラス）選択**
  - 「【兵科選択】」と表示されたエンチャント本アイテムを**右クリック**することで、兵科選択メニューが開く仕様です（詳細な兵科の中身は `ClassMenu` クラス側の実装のため未確認）。
- **アイテムドロップ**
  - ゲーム中はアイテムを手動でドロップ（Qキー等）することはできません（常にキャンセルされます）。
- **死亡時**
  - 死亡してもアイテムやXPはドロップされず、インベントリと防具はリセットされます。ペナルティを気にせず戦闘に集中できる仕様です。
- **観戦（スペクテイター）**
  - `Spectator` 機能が組み込まれています（詳細な操作方法は `Spectator` クラス側の実装のため未確認）。

## 管理者向け補足

| 項目 | 内容 |
|---|---|
| ゲーム進行フラグ | プラグイン内部で管理（`isGameRunning()` で参照可能） |
| チーム所属管理 | プレイヤーごとにチーム名を保持 |
| 切断者の装備保持 | ゲーム進行中に切断したプレイヤーの装備は自動的に保持され、再接続時に復元される |
| ゲーム開始時刻 | 内部で記録・取得可能 |
